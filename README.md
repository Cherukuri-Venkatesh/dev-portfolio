## 🚀 GitHub Pages Deployment Setup

To host this repository on GitHub Pages:
1. Go to your GitHub repository: `https://github.com/Cherukuri-Venkatesh/dev-portfolio`
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Set **Branch** to `main` (or `master`) and folder to `/ (root)`.
5. Click **Save**.
6. Within ~60 seconds, your site will be live at `https://cherukuri-venkatesh.github.io/dev-portfolio/`!
